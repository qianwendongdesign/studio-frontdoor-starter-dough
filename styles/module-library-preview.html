Module Library

Front Door Template Library — Pre-built Layout Modules

Modules are drop-in layout blocks that can be added to any page template. They always look the same by default, ensuring visual consistency across prototypes.

Using modules: Tell your AI agent "Add a StandardCarouselModule at position 4 on the homepage feed"
Customizing: Tell your agent "I want to customize this carousel" — it will eject the module into raw editable code.
