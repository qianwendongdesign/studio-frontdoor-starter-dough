# Column Descriptions: ConsumerDeliveryHabitsTags.tsv

This TSV is generated by `scripts/generate-consumer-tags.cjs` and contains delivery-habit tags for each unique consumer, derived from their GenAI profile in SF Loved Reviews L14D.tsv.

---

## Column Reference

| Column | Description |
|--------|-------------|
| **CONSUMER_ID** | Unique identifier for the consumer. |
| **CONSUMER_NAME** | First name and last initial (e.g., "Marisol A", "Jessica D"). |
| **PRICE_SENSITIVITY_TAG** | One of: **Savings Focused**, **Moderate Spender**, **Premium Shopper**. Inferred from promotion usage and order values. |
| **DIET_TAG** | One of: **Vegetarian**, **Omnivore**, **High Protein**. Inferred from dietary preferences in the profile. |
| **CUISINE_PREFERENCE_TAG** | The main cuisine the consumer orders most (e.g., "Vietnamese", "Mexican", "American"). 1–2 words. |

---

## How to Generate

```bash
npm run classify-consumer-tags
```

Reads `SF Loved Reviews L14D.tsv`, extracts unique consumers and their profiles, applies rule-based classification (no external API), and writes this TSV.

---

## File Format

- **Format:** TSV (Tab-Separated Values)
- **Encoding:** UTF-8
- **Header:** First row contains column names
- **Source:** SF Loved Reviews L14D.tsv `GENAI_CX_PROFILE` column, processed via Claude API
